# Code of Conduct

This project follows a simple standard: be respectful, assume good intent, and make the work easier for the next person.

Unwelcome behavior includes harassment, personal attacks, discriminatory language, or repeatedly derailing technical discussions. Maintainers may remove comments, close issues, or block participants who make the project less safe or useful for others.

If you need to report a concern, open a private channel with the project maintainer.
